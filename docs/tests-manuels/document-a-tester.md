# Export des factures

## Contexte
Les comptables recopient manuellement les factures à la fin de chaque mois.

## Périmètre
Le besoin concerne uniquement les factures validées du mois sélectionné.

## Besoins fonctionnels
Le comptable sélectionne un mois puis télécharge les factures correspondantes.

## Contraintes
Le fichier doit être facile à utiliser et le téléchargement doit être rapide.

## Critères d'acceptation
Le fichier contient toutes les factures validées du mois choisi, sans doublon.

## Délais
La fonctionnalité est attendue avant le 30 novembre 2026.
